# Interface operacional
Interface em português brasileiro para consulta rápida durante a cozinha e as compras. Fundo claro e contraste forte para uso no celular sob iluminação intensa. Sistema visual discreto: superfícies brancas, cinza frio, verde escuro para ações e âmbar para atenção. Tipografia de sistema para velocidade e leitura. Valores alinhados, unidades sempre explícitas, tabelas com rolagem horizontal e formulários com campos grandes. Navegação lateral no computador e faixa horizontal no celular. O painel prioriza estoque em atenção e tarefas abertas; totais financeiros distinguem dinheiro pago de compromissos pendentes. Dados fictícios identificados na demonstração.
